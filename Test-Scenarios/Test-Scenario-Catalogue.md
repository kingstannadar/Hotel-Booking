# Test Scenario Catalogue

This folder contains the scenario-level catalogue for the Hotel Booking Application.

## Coverage

| Module | Scenario coverage |
|---|---|
| Registration | Successful registration, required fields, email and password validation, duplicate email, membership selection |
| Login | Successful and unsuccessful login, required fields, email validation, credential handling, logout/session behaviour |
| My Page | Profile details, image upload and validation, image controls, account deletion |
| Reservation | Reservation plans, guest count, stay duration, date validation, guest details, pricing, reservation submission and confirmation |

## Detailed records

The repository's master Excel workbook contains the detailed test cases, including IDs, test steps, test data, expected results, actual results, status, and defect references. This catalogue is a high-level index and does not replace the detailed workbook.

## Scope note

The latest reviewed workbook contains 221 primary test cases across Registration, Login, My Page, and Reserve Page. Supporting worksheets are retained separately and are not double-counted in the primary total.
