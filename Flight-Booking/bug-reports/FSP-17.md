# FSP-17: Booking Confirmation: no option to return to booking page after successful payment

| Field | Value |
|---|---|
| Priority | Medium |
| Labels | navigation, post-payment, usability, flight-booking |
| Status | Open (reproduced 04-Nov-2026) |
| Environment | https://travel.agileway.net / browser and version not specified / OS not specified |

## Steps to reproduce
1. Log in as a valid user.
2. Book a flight with all data.
3. Pay for the flight.

## Expected result
A button or link to return and book a new flight is shown.

## Actual result
The user is stuck on the flight information page and cannot go back or book another flight.
