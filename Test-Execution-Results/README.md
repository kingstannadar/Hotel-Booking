# Test Execution Results

Test execution results are recorded alongside the detailed test cases in the master Hotel Booking Excel workbook.

The execution records include:
- Test Case ID and title
- Expected Result
- Actual Result
- Status (PASS, FAIL, Pending, or N/A)
- Defect reference or execution notes

## Reporting Notes
- PASS means the observed result matched the expected result.
- FAIL means the observed result did not match the expected result.
- Pending means the result or requirement needs further confirmation.
- Related test cases should reference the same defect ID when they describe the same underlying issue.

The master workbook is the source of truth for execution status and totals. Do not maintain a second independent status count unless it is refreshed from that workbook.
